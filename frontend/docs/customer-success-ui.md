# Customer Success Center UI Documentation

## Overview
The Customer Success Center UI provides SMEs with a unified, high-impact workspace to manage account health, loyalty rewards, referral funnels, customer feedback, and automated retention tasks.

## Key Features & Layout
1. **Executive Header & Banner**: Real-time retention metrics including Retention Rate, Average Health Score, At-Risk Account Count, and Revenue At Risk.
2. **Quick Launcher Cards**: One-click navigation to Customer Health, Loyalty & Rewards, Referral System, and CSAT Feedback workspaces.
3. **Automated Retention Recommendations**: AI-driven retention action cards highlighting accounts at risk of churning and suggested outreach steps.
4. **Pending Success Tasks Panel**: Live task feed showing high-priority outreach tasks generated by low CSAT alerts or health score drops.

## Component Architecture
- `app/dashboard/customer-success/page.tsx`: Main overview hub.
- `lib/customer-success-service.ts`: API client connecting with `/api/customer-success/*`.
- `hooks/use-customer-success.ts`: Custom React Query hooks.
