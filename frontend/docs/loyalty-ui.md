# Loyalty Program & Rewards UI Documentation

## Overview
The Loyalty & Rewards UI enables SMEs to configure custom point rules, view active programs, issue rewards, process redemptions, and view transaction history logs.

## Interface Components
1. **Program Builder Modal**: Allows creation of loyalty programs with custom `pointsPerPurchase` multipliers and `minimumRedemptionPoints` thresholds.
2. **Points Adjustment Dialog**: Administrative tool for manual point grants or deductions with mandatory reason tracking.
3. **Quick Redemption Tool**: In-app interface for redeeming points for store discounts or credits.
4. **Loyalty Transaction Log**: Real-time table displaying points earned, redeemed, balances, and dates across all members.
