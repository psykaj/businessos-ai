# Automation Studio UI

The UI for the Automation Studio serves as the control center for all workflow automations across BusinessOS AI. It is designed for business owners, prioritizing visual layout and clarity over code.

## Key Screens
- `/dashboard/automation` - High-level metrics and recent executions.
- `/dashboard/automation/workflows` - Active/Draft list of custom workflows.
- `/dashboard/automation/templates` - Pre-configured automations tailored for quick value realization.
- `/dashboard/automation/history` - Comprehensive execution audit trail.

## Tech Stack
- **Next.js 15 App Router**
- **React Query** for async state management.
- **Tailwind CSS & Shadcn** for a modern, unified design language.
- **Framer Motion** for subtle entrance animations.
