# Execution History UI

The Execution History provides visibility into background workflow operations.

## Features
- **Tabular View**: Shows execution status (Completed, Failed, Retrying), timestamps, and associated workflows.
- **Error Visibility**: Surfaces error strings directly in the table to quickly identify why an action (like "Send Email") failed.
- **Retry Capability**: For failed executions, users can trigger a manual retry.
- **Performance Monitoring**: Helps IT admins or business owners gauge how much time is being saved by automation tasks.
