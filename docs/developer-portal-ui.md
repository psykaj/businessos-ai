# Developer Portal UI

A central hub for advanced users and developers to manage APIs and integrations.

## Architecture
Located at `/dashboard/developer`, this portal acts as the root interface pointing to:
1. **API Keys**: Manage programmatic authentication.
2. **Webhooks**: Configure real-time event notifications.
3. **OAuth Apps**: Register clients for external integrations.
4. **API Logs**: Audit request traffic.

## Design Highlights
- Clean, un-cluttered landing page featuring primary developer features.
- Links to standard documentation and SDK references.
- Uses large recognizable Lucide icons for easy scannability.
